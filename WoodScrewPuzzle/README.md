# RK Gaming – 3D Wood Screw Puzzle

A standalone mobile-first wood screw puzzle prototype, separate from Brain Puzzle.

## Current prototype
- Responsive touch controls
- Wooden board and metallic screw visuals rendered on canvas
- Tap-to-unscrew interaction, move counter and level progression
- Undo, hint, paid remove tool, board rotation
- Sound effects and vibration where supported
- Local/offline play after the page is available on the device

## Next development milestones
1. Replace the illustrated board with a full 3D scene and physically threaded screw animations.
2. Add real blocking rules, removable wooden layers, and varied level layouts.
3. Add persistent local progress, settings, accessibility and language selection.
4. Add optional online features (leaderboards/cloud saves) with a backend.
5. Package and test an Android APK/AAB.

Online services are not implemented in this prototype yet; the puzzle itself runs locally.
